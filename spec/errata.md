# Errata — specification corrections

Corrections to the specification name the affected stable requirement
(`ABP-<SURFACE>-<kebab-tag>`), the releases affected, and the
re-certification: the conformance corpus, the gates, and the mutation
evidence must hold over the corrected text (a correction that breaks
the chain is a revision, not an erratum). Errata are append-only.
