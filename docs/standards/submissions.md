# Standards submissions — Agent Blueprint Protocol

This file records only what has been submitted to a standards body or registry, when, and with what identifier,
together with the body's own published status string. It begins empty.

**Nothing has been submitted.** There is no entry below.

## Vocabulary

Each entry, when one exists, carries one of four statuses and nothing else:

- `prepared` — the package exists in this repository at a named commit and has not left it;
- `submitted <date> <identifier>` — sent to the named body on that date under that identifier;
- `acknowledged <date> <reference>` — the body acknowledged receipt with that reference;
- `published <venue identifier>` or `adopted <venue identifier>` — the body's own published outcome.

No forward-looking word ("in progress", "under review", "expected") is part of this vocabulary, because each is a
claim about another party's future behavior.

## Four things this file never means

- A submission is not an adoption.
- A draft is not a standard.
- A body's interest is not an acceptance.
- A registration request pending review is not a registration.
