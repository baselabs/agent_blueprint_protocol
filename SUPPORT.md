# Support

- **Usage and design questions** — [GitHub Discussions](https://github.com/baselabs/agent_blueprint_protocol/discussions).
- **Bugs** (behavior diverging from the specification or the shipped
  corpus) — open an issue with the repository's bug-report template.
- **Extension namespace registration** — open an issue with the
  registry-request template, following `spec/registry/OPERATIONS.md`.
- **Security** — private vulnerability reporting via the repo's Security
  tab; see [`SECURITY.md`](SECURITY.md). Do not open a public issue for
  vulnerabilities.

The package is deliberately inert: it grants no authority and starts
nothing. Support questions that turn out to be authorization, tenancy, or
policy problems belong to your host runtime, not this protocol — the
[host-integration guide](documentation/host-integration.md) draws that
boundary.
