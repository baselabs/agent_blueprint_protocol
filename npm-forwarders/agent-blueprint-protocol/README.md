# agent-blueprint-protocol

Use [`@agent-blueprint-protocol/verifier`](https://www.npmjs.com/package/@agent-blueprint-protocol/verifier) directly:

```bash
npm install @agent-blueprint-protocol/verifier
```

This package only runs the command from `@agent-blueprint-protocol/verifier`, so that this name leads to the same project. It adds no code of its own.

It accepts any newer version of `@agent-blueprint-protocol/verifier`. If you need stability, depend on the scoped package and
commit a lockfile. This package is published by hand and carries no provenance attestation; the scoped package
is where releases and attestations live.
