[ABP] Agent Blueprint Protocol

Describe an agent with a portable contract.

Agent Blueprint Protocol provides language-neutral artifacts for agent capabilities, deployment bindings, and task records. Elixir and TypeScript verifiers report protocol facts. Verification is non-authorizing and never grants permission to act.

Three artifacts

Each artifact has a defined shape and a public specification.

ArtifactPurpose
Blueprint CoreDescribes identity, ports, capability requirements, bounds, and extensions.
Deployment ManifestBinds one Blueprint release to environment-specific descriptors and bounds.
Federation TaskEnvelopeRecords a task's identity, state, and terminal commitments for transport.

Verification reports facts

Protocol validity never grants authority. A consuming host makes its own decisions.

What it checks

  • Artifact structure and canonical JSON bytes
  • Protocol revision and registered extensions
  • Deployment bindings and effective bounds
  • Evidence and typed denials

What the host owns

  • Identity and local policy
  • Whether an operation may run
  • Effect ownership and execution
  • Evaluation and operational records

Try it

Run the TypeScript verifier from npm. For Elixir, add the dependency below to mix.exs, then run mix deps.get.

npx @agent-blueprint-protocol/verifier@1.0.0-rc.3
{:agent_blueprint_protocol, "~> 1.0.0-rc.3"}
mix deps.get
