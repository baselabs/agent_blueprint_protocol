Federation extension

The registered namespace for the Agent Blueprint Protocol federation profile.

The profile carries a non-authorizing Federation TaskEnvelope in A2A metadata and MCP _meta. It describes lineage, release and deployment digests, bounds, evidence commitments, and mapped logical task states.
